# Kraka

> Kraka Technologies GmbH (Berlin, Germany) builds an AI platform for industrial
> shop-floor execution. Its core product, Kraka Studio, turns a plain video
> recording of a task into a standardized, multilingual, step-by-step work
> instruction (SOP). Specialized modules extend that core into training,
> maintenance and quality workflows. Kraka positions itself as closing the
> "execution gap": where ERP systems manage data, Kraka shows the actual
> execution on the factory floor.

Kraka does NOT publish a public API, developer portal, SDK, or API
documentation as of 2026-07-19. Marketing pages reference connectivity to
existing ERP and MES systems, but no public interface is documented. Treat any
claim of a public Kraka API as unverified.

## Platform and modules

- [Kraka Studio](https://gokraka.com/module/kraka-studio): Core platform. Video
  in, standardized multilingual step-by-step work instruction out.
- [Schulungs-Hub / Training-Hub](https://gokraka.com/module/schulungs-hub):
  Basic, onboarding and one-point training on autopilot; coordinates workforce
  qualification with audit-ready records.
- [Maintenance-Hub](https://gokraka.com/module/maintenance-hub): AI assistant
  for fault diagnosis and repair based on available maintenance data; reduces
  machine downtime. Advertises connection to existing ERP systems.
- [Quality-Hub](https://gokraka.com/module/quality-hub): Intelligent checklists
  guiding teams through critical processes with AI-based real-time error
  detection; advertises synchronization with MES/ERP.
